## 🌌 Overview

**Quantsuite** is an autonomous trading intelligence platform engineered for quantitative hedge funds, algorithmic traders, and visionary market participants. Built on a foundation of multi-agent AI systems, real-time regime detection, and institutional-grade backtesting infrastructure.

> *"Markets are systems, not workflows. We detect signals, shape strategies, and manage risk before others even react."*

## 🚀 Quick Start

```bash
# Clone the repository
git clone https://github.com/quantsuite/landing.git
cd landing

# Install dependencies
npm install

# Start development server
npm run dev

# Build for production
npm run build
```

The application will be available at `http://localhost:3000`

## ✨ Key Features

### 🎭 Premium Animations
- **15+ CSS Keyframes**: `fadeIn`, `slideInUp`, `scaleIn`, `float`, `pulseGlow`, `textShimmer`, `marquee`, `gradientShift`, `breathe`, `revealUp`
- **Staggered entrances**: 0.1s–0.8s delays for sequential reveals
- **Hover micro-interactions**: Lift, glow, scale, color transitions
- **Reduced motion support**: Full `prefers-reduced-motion` compliance

### 🔮 Glassmorphism System
```css
.glass        /* 16px blur, subtle transparency */
.glass-strong /* 24px blur, elevated surfaces  */
.glass-card   /* 20px blur, interactive cards   */
```

### 💡 Glow Effects
- `glow-cyan` / `glow-green` / `glow-amber`: Ambient element shadows
- `text-glow-cyan`: Neon text shadows for headlines
- Pulsing status indicators across all interactive elements

### 📐 Responsive Grid
| Breakpoint | Layout Behavior |
|------------|----------------|
| `< 640px` | Single column, hamburger nav, vertical timeline |
| `640–1024px` | 2-column grids, inline nav, horizontal timeline |
| `> 1024px` | Full layout, floating metrics, perspective grid |
